## 2. Data Flow Diagram - DNA Sequence Analysis

```
┌─────────────┐
│    User     │
└──────┬──────┘
       │ 1. Upload DNA Sequence
       ↓
┌─────────────────────┐
│  Web Interface      │
│  (index.html)       │
└──────┬──────────────┘
       │ 2. POST /analyze
       ↓
┌─────────────────────┐
│  Flask Route        │
│  @app.route()       │
└──────┬──────────────┘
       │ 3. Validate Input
       ↓
┌─────────────────────┐
│  DNA Analysis       │
│  Engine (utils.py)  │
└──────┬──────────────┘
       │ 4. Process Sequence
       ├─→ Calculate GC Content
       ├─→ Detect Mutations
       ├─→ Find Patterns
       └─→ ML Prediction
       ↓
┌─────────────────────┐
│  ML Model           │
│  (XGBoost/SKLearn)  │
└──────┬──────────────┘
       │ 5. Generate Predictions
       ↓
┌─────────────────────┐
│  Report Generator   │
│  (PDF/JSON)         │
└──────┬──────────────┘
       │ 6. Create Report
       ↓
┌─────────────────────┐
│  Database           │
│  (SQLite)           │
└──────┬──────────────┘
       │ 7. Store Results
       ↓
┌─────────────────────┐
│  Voice Synthesis    │
│  (pyttsx3/gTTS)     │
└──────┬──────────────┘
       │ 8. Generate Audio
       ↓
┌─────────────────────┐
│  Response to User   │
│  (JSON + Audio)     │
└─────────────────────┘
```

       ↓

       ↓

       ↓
